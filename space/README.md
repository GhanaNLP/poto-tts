# poto-tts

English text-to-speech that pronounces Ghanaian words properly. Eight sentences,
synthesised twice: once with ordinary Kokoro and once through poto-tts. Same model,
same speaker, same text — only the front-end differs.

The voices are Kokoro's British and American speakers, so this is **not** a
Ghanaian accent. What changes is what they say.

Regenerate this page with `python tools/build_space.py` in
[GhanaNLP/poto-tts](https://github.com/GhanaNLP/poto-tts).
