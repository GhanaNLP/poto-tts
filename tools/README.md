# Tools

Build-time scripts. None of these is needed to speak; the voice ships compiled.

| | |
|---|---|
| `build_espeak_dict.py` | thin wrapper over `poto-tts dict` |
| `classify_lexicon.py` | regenerate `poto_tts/data/ghanaian-words.txt`: which lexicon entries a Ghanaian speaker pronounces by local rules |
| `measure_coverage.py` | how many Ghanaian words come out right, stock Kokoro against poto-tts |
| `build_space_audio.py` | the audio for the comparison page |
| `build_space.py` | the comparison page itself |
